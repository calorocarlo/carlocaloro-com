Implement_Azioni / 2002

Implement_Azioni is a work in which the user is immersed in a flow of sequential visual information, displayed in a series of charts by means of choices and actions. Implement_Azioni, therefore, follows a path, along which the spectator is overwhelmed by sensory stimuli brought about by sounds (the use of a radio or the possibility of using a microphone reciting a text) from spatial situations. The user has the task of re-interpreting an action from a “deterministic” viewpoint, implementing a program in an absolutely physical-visual way, the work normally carried out by a PC was used.
